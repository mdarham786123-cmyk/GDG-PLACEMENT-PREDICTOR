# GDG Tech Team Task 1: Placement Readiness Predictor

This repository contains an end-to-end Machine Learning pipeline built using Python and Scikit-Learn to predict student placement status.

## Files
* `Untitled0.ipynb`: Google Colab notebook containing data cleaning, train-test splitting, and evaluation of Logistic Regression and Random Forest models.
* `DECISION.md`: Comprehensive engineering decisions, model evaluation metrics, and post-mortem notes.

## Tech Stack
* Python 3
* Pandas, NumPy, Scikit-Learn
